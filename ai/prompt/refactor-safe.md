# Safe Refactor Prompt

Objectif :
Refactoriser un module de manière sécurisée.

IMPORTANT :

* conserver comportement existant
* ne pas modifier architecture globale
* éviter breaking changes

Vérifier :

* duplication logique
* méthodes trop longues
* responsabilités mélangées
* noms peu explicites

Contraintes :

* petits changements progressifs
* code plus lisible
* architecture plus claire

Sortie attendue :

* problèmes identifiés
* plan refactor
* code refactorisé

# Debug Module Prompt

Contexte :
Projet Streamer.bot XP System.

Objectif :
Débugger un module sans casser l’architecture.

IMPORTANT :
Ne jamais réécrire tout le système.

Méthode :

1. Identifier cause probable
2. Expliquer problème
3. Corriger localement
4. Préserver architecture actuelle

Contraintes :

* correction minimale
* aucune régression
* aucune refonte inutile

Sortie attendue :

* analyse problème
* cause racine
* correction proposée
* code corrigé

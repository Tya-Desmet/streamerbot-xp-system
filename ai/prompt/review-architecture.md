# Review Architecture Prompt

Analyse l’architecture actuelle du module.

Objectifs :

* détecter duplication
* détecter dépendances inutiles
* améliorer maintenabilité
* améliorer compatibilité IA

Vérifier :

* responsabilités séparées
* fichiers trop gros
* logique dupliquée
* couplage fort
* architecture scalable

IMPORTANT :
Ne PAS proposer de refactor global.

Proposer uniquement :

* améliorations locales
* améliorations progressives
* architecture plus claire

Sortie attendue :

* problèmes détectés
* solutions proposées
* niveau de priorité
